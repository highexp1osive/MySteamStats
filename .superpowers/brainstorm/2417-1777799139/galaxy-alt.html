星系视图替代方案

Three.js 太重且纹理加载不稳定，选一个更轻量的方向

A

纯 CSS 轨道环

封面按时长分布在多层同心圆轨道上，CSS 动画旋转，原生 img 标签加载封面

优点

  • 零额外依赖，原生 img 加载稳定
  • CSS transform 性能好，动画流畅
  • 页面体积几乎不增加

缺点

  • 只能做 2D 平面环绕，无 3D 景深
  • 封面会重叠，需要控制数量
B

D3.js 力导向散点图

封面作为节点，中心头像为引力源，自然散布不重叠

优点

  • 自动避让不重叠，适合大量封面
  • 支持拖拽、悬停、缩放
  • 原生 img 标签嵌入 SVG foreignObject

缺点

  • 引入 D3.js（~50KB）
  • 力导向布局需要计算时间
C

Canvas 2D 星空散射

全 Canvas 绘制，封面以星球形态随机散布在暗色星空背景中

优点

  • 完全控制渲染，不依赖外部库
  • 可以做粒子、光晕等特效
  • 性能最好

缺点

  • Canvas 绘制图片也有跨域问题
  • DOM 事件绑定较繁琐
  • 代码量最大
