技术栈方案对比

公开平台 · 代码简洁 · 安全 · 长期运维友好

A

Next.js 14 + Prisma + PostgreSQL

前后端一体，TypeScript 全覆盖，Vercel 一键部署

优点

  • 一个仓库搞定全栈，代码量最少
  • Server Actions / API Routes 天然安全（无暴露端点）
  • Vercel 免费额度足够起步，运维零成本
  • TypeScript 端到端类型安全
  • 社区庞大，AI 辅助开发效率最高

缺点

  • Vercel 平台有一定绑定
  • Serverless 函数有 60s 超时（AI 分析可能受限）
B

React SPA + Express + PostgreSQL

传统前后端分离，自建 API 服务器

优点

  • 前后端独立部署，灵活控制
  • 无超时限制，适合长时 AI 分析
  • 不绑定任何云平台

缺点

  • 需要管理服务器/容器，运维成本高
  • 前后端类型同步麻烦
  • 需自行处理 CORS、安全、认证中间件
  • 代码量大概是 A 方案的 1.5-2 倍
C

Django + HTMX + PostgreSQL

Python 全栈，模板渲染 + 少量 JS

优点

  • Python 生态方便对接 AI/数据分析
  • Django 内置认证、后台管理，开箱即用
  • 成熟稳定，适合数据密集型应用

缺点

  • 前端交互不如 React 流畅
  • 词云、可视化等需要额外前端工作
  • 部署比 Vercel 方案重
