为什么选 PostgreSQL

  • 多用户并发读写无压力（你的公开站时期）
  • docker-compose 一键同时启动 App + DB
  • 自托管用户也只是多等 3 秒拉镜像
  • Prisma 切换 SQLite ↔ PG 只需改一行配置

权衡

  • 比纯 SQLite 多一个容器
  • 首次冷启动需要拉取 PG 镜像（~150MB）
  • 两个环境变量需要配置（DB 用户名/密码）
