Steam 数据获取方式

决定能拉取哪些用户数据，直接影响后续功能介绍

A

仅限公开档案

用户 Steam 登录即可，无需任何额外配置

优点

  • 用户体验最流畅，一键登录即用
  • 零额外门槛，转化率高
  • 不需要用户申请任何密钥

缺点

  • 只能拉取公开档案数据
  • 用户需将 Steam 档案设为公开
  • 无成就、好友等深度数据
B

公开档案 + Steam API Key

用户需自行申请免费 Steam Web API Key

优点

  • 数据更丰富（成就、好友列表等）
  • 可做更多维度的分析

缺点

  • 用户需额外操作，流失率高
  • 增加前端配置页面和说明文档
  • 普通用户觉得麻烦就放弃了
C

先做 A，后续可选升级到 B ⭐ 推荐

MVP 阶段门槛最低，后续可加 B 做深度模式

优点

  • 兼顾当下和未来的灵活性
  • MVP 链路最短，快速验证
  • 后期可作为"深度模式"卖点

缺点

  • 架构上需预留扩展点
