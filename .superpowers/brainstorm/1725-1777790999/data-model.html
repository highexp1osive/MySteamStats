数据模型设计

PostgreSQL · Prisma ORM · 5 张核心表

User — 用户

id UUID # 主键
steamId String # Steam 64位ID，唯一
displayName String # Steam 昵称
avatarUrl String # Steam 头像 URL
profileUrl String # Steam 个人资料链接
lastSyncAt DateTime # 上次数据同步时间

Game — 游戏（全局共享）

id UUID
steamAppId Int # Steam App ID，唯一
name String
coverUrl String # 封面图 CDN 地址
headerUrl String # 大横幅
genres String[] # 类型标签

UserGame — 用户游戏关联

id UUID
userId UUID → User
gameId UUID → Game
playtimeMinutes Int # 总游玩时长（分钟）
playtime2Weeks Int # 近两周时长
lastPlayedAt DateTime? # 最后游玩时间

UserReview — 玩家评测

id UUID
userId UUID → User
gameId UUID → Game
content Text # 评测全文
isRecommended Boolean # 推荐/不推荐
steamReviewId String # Steam 评测 ID

AIAnalysis — AI 分析缓存

id UUID
userId UUID → User
type Enum # personality | review_style | recommendation
content JsonB # AI 分析结果
generatedAt DateTime
