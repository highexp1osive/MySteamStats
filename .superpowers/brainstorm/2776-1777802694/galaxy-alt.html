星系视图替代方案

Three.js 太重且纹理加载不稳定，选一个更轻量的方向

A

纯 CSS 轨道环

封面按时长分布在多层同心圆轨道上，CSS 动画旋转，原生 img 标签加载封面

优点

  • 零额外依赖，原生 img 加载最稳定
  • CSS transform 性能好，动画流畅
  • 页面体积几乎不增加
  • 可直接复用 GameCard 组件

缺点

  • 2D 平面环绕，无 3D 景深
  • 封面多时会拥挤
B

D3.js 力导向散点 + 中心引力

封面作为节点散布，中心头像为引力源，力仿真自动避让不重叠

优点

  • 自动避让不重叠，适合大量封面
  • 支持拖拽、悬停、缩放
  • 封面用原生 img 标签（foreignObject）

缺点

  • 引入 D3.js（~50KB）
  • 首次布局需计算（1-2秒）
